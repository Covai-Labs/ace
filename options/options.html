Keyboard Shortcuts

Copy Markdown Instantly copy current chat in Markdown format
Alt + Shift + C
Download Markdown Directly download current chat as a .md file
Alt + Shift + D
Open in Preview Tab Open chat in full-page Markdown preview
Alt + Shift + P
Firefox Shortcut Customization To customize shortcuts in Firefox: Open about:addons → Click the gear icon ⚙️ at top-right → Select "Manage Extension Shortcuts".
